# X4-950 水平风 PINN 重训练设计草案

日期：2026-11-10。状态：供审阅的计划依据；没有生成训练数据、训练模型或切换运行权重。

## 目标与接口

用户要求：从仿真生成数据，重新训练当前 PINN 以适配本项目 X4-950，动力学参数参考 XML；没有实测数据。用户明确指定水平风速 **0–3 m/s**。

本模型的目的，是近似一个公开参数、独立于旧 PINN 的 X4-950 气动参考模型，生成当前控制测试所需的水平风扰。输入为世界系速度、姿态、机体系角速度和世界系水平风；输出为风引起的三轴加速度增量，现有施力层继续只施加世界 XY 分量。质量、惯量、几何、旋翼位置与执行器定义取自本项目 XML。

首版按当前默认场景：X4-950 + Airbot Play，机械臂及夹爪固定在初始姿态、无额外载荷、自由空间、均匀稳态水平风。不覆盖机械臂动作、近墙/地效、桨叶尾流、旋翼气动干扰、直接气动力矩或真实飞机标定。

这里的“固定”是参考气动几何的建模假设：当前仿真仍通过原有关节控制保持初始姿态，不新增焊接或锁臂。闭环须记录实际关节偏离；不能在参考端偷偷改用活动臂几何，却继续把不含关节信息的 6 维网络视作同一模型。

- 初始整机质心相对根坐标系约 `[0, 0, -0.0587247] m`。
- 初始姿态刚性聚合惯量约为 `[[0.345645,0.000620,0.001523],[0.000620,0.376016,0.000033],[0.001523,0.000033,0.351378]] kg·m²`。这是参数核对值，不替换原多体模型。
- 四个推力作用点位于 `x/y=±0.3358757 m, z=0.065 m`；按 actuator/site 名称绑定。

- XML 未给出经实验辨识的阻力系数、真实旋翼 RPM–推力关系或电机气动滞后。旋翼 spin 执行器用于视觉旋转，不能当作真实 RPM。

## 方案选择与假设

1. **建议首版：XML 几何派生的分部件二次阻力参考模型。** 参数透明、标签可直接计算、无旧 PINN 依赖。代价是气动力学简化，不能声称得到实物标定。
2. MuJoCo 内建流体力：可作为后续独立交叉检查；等效几何、附加质量、力矩与双重几何计数需要额外处理，不作为首版必需项。[官方模型范围](https://mujoco.readthedocs.io/en/stable/computation/fluid.html)
3. CFD 或实测辨识：当前没有对应数据和验证条件，暂不纳入。

XML 确定动力学与几何，不能唯一确定阻力系数。首版显式假设空气密度 `1.225 kg/m³`、每个等效阻力轴的标称 `Cd=1.0`；它们是仿真参考配置，不是从 XML 识别的实物参数。阻力公式依据 [NASA 阻力方程](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/drag-equation/)；以下分部件、逐轴实现属于本项目明确选择的近似。

每个部件只保留一个等效几何，半轴从 XML primitive 或 mesh 包围尺寸派生；使用 `A_i=π r_j r_k` 作为等效椭球轴向面积。记录选取依据，避免 visual/collision 重复计算；不把四个 `thruster-*` 薄盘代理当作整片实体桨盘，不把 floor、site 或相机算入阻力部件。没有合适 collision proxy 的机械臂部件，可使用其 visual mesh 派生单一包围几何，明确标注近似。

在根坐标系 B 中，部件 j 的局部相对风速为

`u_j = Q_jᵀ [R_WBᵀ(v_O^W-w^W) + ω^B × r_j^B]`，

局部阻力 `f_j = -0.5 ρ (Cd_j ⊙ A_j) ⊙ u_j ⊙ |u_j|`，总力 `F_ref^B=Σ Q_j f_j`。根点 O 是 `quadrotor_950_pos` 坐标原点；不是整机质心。固定机械臂时各部件的 r、Q 为常量。参考力矩可记录为诊断，但首版不训练或额外施加该力矩。

## 标签与模型

对同一状态、同一机械臂姿态，分别计算有风和无风参考力：

`y_wind^W = P_xy [F_ref^W(s,w)-F_ref^W(s,0)] / m_total`，其中 `P_xy=diag(1,1,0)`。

同时保存两次完整三轴参考力，避免由速度数值差分、PX4 闭环响应、旧 PINN、EMA 或限幅产生训练标签。这里学习的是**风造成的增量**；无风阻力不被再次混入当前默认无风基线。

首批数据来自对参考模型的离线状态扫描，不是已完成的 SITL 飞行采集，也不等于真实风洞数据；动力学闭环验证另行执行。

首版参考模型只依赖相对速度与角速度、固定几何和参考气动参数，不包含旋翼诱导气流。因此建议移除旧 17 维接口中的 Hummingbird 悬停 RPM 与旋翼残差分支，使用 6 维机体系输入 `[v_air^B(3), ω^B(3)]` 预测完整参考气动加速度 `gθ∈R³`。网络为二次阻力先验 + `6→64→64→3` Tanh 残差 MLP；阻力先验的非负逐轴系数由标称参考模型单位轴向样本拟合并存档。

在线使用两行批量推理：`R_WB[gθ(R_WBᵀ(v_O-w),ω)-gθ(R_WBᵀv_O,ω)]`。外层仍按现有逻辑投影 XY、滤波限幅、乘整机质量；w=0 直接返回精确零。输入/输出单位与新版本元数据必须显式保存，不能复用旧 normalizer 或把原 17 维权重误载入新网络。

不沿用旧机型的 C4 机体对称性损失，也不强制 X/Y 归一化统计相等。当前机械臂初始几何不保证该对称性。世界/机体坐标变换提供坐标协变性，不涉及电机编号置换。

## 验证边界

标称网络只拟合一个冻结的参考配置。改变 Cd/面积的模型用于独立敏感性测试，不将不同隐藏参数对应的冲突标签混进同一个不带参数条件输入的训练集。

需分别报告：XML 参数一致性、参考模型自身性质、网络拟合误差、不同参考参数下的敏感性、PX4 闭环表现。没有实测数据，不能宣称真实 X4-950 气动精度。[模型验证范围](https://www.grc.nasa.gov/www/wind/valid/tutorial/valassess.html)

训练范围是**合风速** `||w_xy||≤3 m/s`，不是每轴各 3 m/s；`[3,3,0]` 不在范围内。首版不默认采集或测试超过 3 m/s 的风。当前运行代码、旧权重和 PX4 保持不变，待后续实现与验收后再切换。
