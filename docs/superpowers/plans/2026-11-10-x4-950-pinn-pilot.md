## Frozen pilot choices (before generation/training)

- 3000 same-state pairs, sampling seed 7, 10 independent states per sampling
  group; group partitions: 2000 train / 500 validation / 500 pilot holdout.
  Separate seeded streams, speed/direction grids and group IDs by partition.
  Zero/3 m/s boundaries use independent states; check transformed core inputs
  for cross-partition duplicates. Holdout is diagnostic, not a final test set.
- Fixed nominal reference only; mass 8.0004 kg, frozen initial arm geometry,
  horizontal resultant wind <=3 m/s. Save complete forces/moments and XY labels.
- X4WindAeroV1: 6 normalized body inputs, fixed nonnegative unit-axis quadratic
  prior plus 6→64→64→3 Tanh residual. Full body acceleration and world XY pair
  losses; train-only normalization, acceleration scales >=0.05 m/s².
- CPU float32, one Torch thread, seed 42, deterministic algorithms; AdamW
  1e-3 / weight decay 1e-5, batch 1024, max 200 epochs, patience 20,
  ReduceLROnPlateau factor 0.5 / patience 5, gradient norm clip 1.
  Positive-work penalty 0.01 on full acceleration at omega=0 only.
- Provisional pilot diagnostics: XY per-axis RMSE <=0.05 m/s², vector error
  P95 <=0.10 m/s² and nonzero-wind normalized vector RMSE <=5%; compare zero
  predictor. These are not final-training acceptance evidence and will not be
  relaxed after viewing holdout. Exact zero wind / applied Z must hold.
- Benchmark warmed scalar pair inference on the same CPU, including common
  frame transformation and XY projection, no EMA/clip; report NumPy float64
  teacher versus Torch float32 proxy precision explicitly.
